3How a run becomes a chart indicator in stock-terminal

    
Each step updates live for the selected run. Nothing in the main repo's code changes. The trained model is a JSON file that the backend and frontend pick up.

    
    
    
    
      Which parameters does the chart use? In devSignalMlDef.js the indicator looks up
      per_symbol[<chart symbol>].params first. If the symbol wasn't trained, it uses global_fallback.params
      (the median of each knob across symbols). If neither exists, it draws no markers and the legend says
      "no tuned params for <symbol>". Knobs that weren't tuned keep Dev Signal's defaults.
